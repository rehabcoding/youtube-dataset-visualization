# youtube-dataset-visualization

Trying out a data science project I picked from [Codedex](https://www.codedex.io/projects/visualize-youtube-data-with-plotly).
I will create data visualizations of popular YouTube channels using Python, Pandas, and Plotly Express. I will use a histogram to look at subscriber counts, a pie chart to compare video categories, and a box plot to find patterns in the years that creators started YouTubing.

## About Dataset
I will use the "Most Subscribed YouTube Channels" dataset from [Kaggle](https://www.kaggle.com/datasets/surajjha101/top-youtube-channels-data)

As the name suggests, it contains data about the top 1000 YouTube channels.

There are seven columns:

rank: Rank of the channel as per total subscribers (1-1000)</br>
youtuber: Channel name</br>
subscribers: Total number of followers</br>
video views: Total views of all the videos combined</br>
video count: Number of videos uploaded</br>
category: Channel genre</br>
started: The year that the channel started</br>
